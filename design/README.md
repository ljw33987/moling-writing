# 墨灵写作 · UI 设计稿

两套**完整且互相独立**的视觉语言，共用同一套信息架构与结构片段：

| | 设计系统 A「Studio Zero」 | 设计系统 B「AXIOM 玄序」· 商务范 |
|---|---|---|
| 气质 | 冷白雾面 / 轻盈 / 工具感 | **深藏蓝 / 香槟金 / 工程化栅格 / 商务范** |
| 主色 | 电光靛蓝 `#4F46E5` + 紫 AI 渐变 | 深藏蓝 `#1C3D6E` + 香槟金 `#A8823C` |
| 几何 | 大圆角 14px + 柔阴影 | **方正 2–5px + 1px 描边分层，几乎无阴影** |
| 顶栏 | 白色毛玻璃 | **墨蓝实底 + 金色下划线 + 金色标识** |
| 底纹 | 纯色 | **44px 工程网格线** |
| 字体 | Inter / 苹方 | Segoe UI / 苹方，**数字全部 tabular 等宽** |
| 稿件 | `out/`（9 桌面 + 9 移动） | `out/business/`（9 桌面 + 9 移动） |

> 功能不做任何删减，只更换呈现方式。本目录为**设计稿**，尚未改动 `src/` 下任何代码。
> **导航方案已定稿：② 顶部横向导航**（两套主题共用）。`out/variants/` 为备选范式归档。

## 〇、设计系统 B「AXIOM 玄序」· 商务范（`out/business/`）

> 完整规格见 **第八节**。以下先说明与 Studio Zero 的分野。

### 三条主张

| 主张 | 具体做法 |
|---|---|
| **压得住** | 顶栏从白底换成**墨蓝实底**（#0E1B2E）+ 金色品牌印记 + 2px 金色底线；正文区铺 **44px 工程网格**做底纹，卡片、表格、图表一律靠 1px 描边分层而不是投影 |
| **讲数据** | 全站数字改 `tabular-nums` 等宽对齐；KPI / 统计块用 22–26px 大号数字 + 环比涨跌标签；表格表头小号大写字距；深色模式配「墨蓝黑 + 金」而非简单反色 |
| **有质感** | 香槟金（#A8823C / #C9A96A）只用在**四个地方**：品牌印记、选中下划线、分区标题标记条、正文书脊 —— 克制地做点缀，不铺满 |

### 形状与字体的根本转向

| 维度 | Studio Zero | AXIOM 玄序 |
|---|---|---|
| 卡片圆角 | 14px | **4px** |
| 按钮圆角 | 9px | **3px** |
| 小标签圆角 | 6–8px | **2px** |
| 卡片阴影 | 常态 `xs`，hover 升 `lg` | **几乎不用，靠 1px 描边分层** |
| 字体 | Inter 优先 | **Segoe UI 优先**（系统字体，零依赖） |
| 正文 | 16px / 2.05 行高 | 15.5px / 2.0 行高 + **左侧 3px 金色书脊** |

### 落地方式

AXIOM 是**覆盖层**：`base.css`（结构与组件）+ `business.css`（视觉层）叠加生效，HTML 结构片段一字未改。
写死在 HTML 里的 483 处颜色由构建期调色板映射一次性换掉：

```powershell
cd design; $env:THEME='business'; node build.mjs   # 商务范 → out/business/
cd design; $env:THEME=$null;      node build.mjs   # Studio Zero → out/
```

## 一、为什么是这套设计

现网是「暖色纸感 + 顶部导航条 + 各页再放一层竖导航」的双层导航结构，视觉偏旧、层级偏碎。

新版 **Studio Zero** 的三条主张：

| 主张 | 具体做法 |
|---|---|
| **一处导航** | 全局**顶部横向导航**（单层 7 项），顶栏右侧只留全局搜索 + 消息 + Token + 头像；页内分区改用分段控件 / 横向标签行，不再叠加竖导航 |
| **冷白清爽** | 去掉纸纹、暖黄、宋体、墨韵；改冷白底（#F5F6F9）+ 1px 冷灰描边 + 无衬线字体，靠留白和层级说话 |
| **AI 有辨识度** | 主色电光靛蓝 #4F46E5；所有 AI 相关元素（助手面板、AI 草稿块、自动连载、预设指令）统一用 **靛→紫渐变**，一眼区分「人写的」和「AI 写的」 |

### 顶部导航的结构

```
[墨] 墨灵写作 │ 工作台 编辑器 AI工具箱 广场 设定库 用户中心 后台 │ [搜索⌘K] [🔔3] [128,460] [梧]
```

- 7 个全局入口横向排列，当前页高亮为「靛蓝浅底 + 靛蓝文字」
- 编辑器页在其下方再叠一条**编辑工具条**（AI 连载 / 长篇工具 / 搜索 / 导出 / 版本历史 / 字数目标 / 发布 / 模式切换）
- 管理后台在顶栏下方再叠一条**二级标签行**（总览/用户/作品/订单/AI日志/公告/群发/邮箱配置/兑换码/平台文档/平台配置），11 项一行放得下，不再需要独立侧栏
- 1280px 以下导航项收敛为「图标 + 文字」，更窄时折叠进「更多」

## 三、导航范式对比（已定稿：② 顶部横向）

同一套视觉语言、同一批功能，**只换导航载体**。四稿可横向对比（备选稿已归档到 `out/variants/`）：

| 方案 | 状态 | 稿件 | 形态 | 适合谁 |
|---|---|---|---|---|
| ① 左侧导航栏 | 备选 | `variants/02…09` | 248px 固定左栏，全局导航常驻 | 功能多、层级清晰、桌面端重度用户 |
| **② 顶部横向导航** | **✅ 已定稿** | `out/01…09` | 单层顶栏横向菜单，内容全宽（书架可放 5 列） | 想要经典稳妥、横向空间利用率最高 |
| ③ 零导航 + 命令面板 | 备选 | `variants/12/13` | 界面不常驻任何导航，只留 ⌘K 胶囊；工作台变成**磁贴启动器** | 追求极简、键盘流、写作时想彻底屏蔽界面 |
| ④ 底部悬浮 Dock | 备选 | `variants/14/15` | 无顶栏导航，底部居中毛玻璃胶囊 Dock（macOS 风格） | 想要新颖、有辨识度、视觉上最出彩 |

### 已定稿方案的落地要点

- 顶栏 7 项横向导航，1280px 以下收敛为「图标 + 文字」，更窄时折叠进「更多」下拉
- 编辑器页在顶栏下叠一条**编辑工具条**；管理后台叠一条**二级标签行**（11 项一行放得下）
- 设定库 / 用户中心内部的分区导航改为**分段控件 + 侧边设置清单**，不再占用整列全局宽度
- 全宽带来的收益：工作台书架 4→5 列、广场 4→5 列、设定卡 3→4 列、后台 KPI 4→5 列

## 七、落地建议（下一阶段）

1. **先换令牌，不换结构**：把 `src/app/globals.css` 的 `:root` / `.dark` 变量整体替换成本目录 `base.css` 的取值，页面观感立刻翻新七成。
2. **再改导航**：`TopBar` 保留结构、改为横向排列（去掉 logo 与导航之间的分割、去掉"工作台/编辑器"的重复项），工作台内的 `.studio-workspace-nav` 竖导航**直接删除**——它就是"双层导航"的根源。
3. **后台**：现有 11 个 Tab 改成顶栏下的二级标签行（`.subnav`），删掉 `admin-view.tsx` 里自己的 TabsList 布局。
4. **组件对齐**：现有 shadcn/ui 组件大多基于 `--primary/--muted/--border` 等语义变量，替换令牌后**基本无需改组件代码**，只需调整少数写死颜色的小组件。
5. **写作器样式**：`globals.css` 里的 `.novel-paper-sheet`（稿纸 + 朱色栏线）建议改成「纯白纸面 + 无栏线」，与新系统统一。
6. **`studio-*` 类名**：现网有大量布局决策写在 `globals.css` 的 `studio-` 前缀类里，重写时需同步替换；`studio-workspace-layout` 的左侧栏相关规则可以整段删掉。
7. **响应式**：顶栏 7 项在 1280px 以下要收敛，建议用 `hidden lg:inline` + 「更多」下拉兜底。

### 与 Studio Zero 的结构关系

**信息架构、页面结构、组件语义完全一致** —— 两套主题共享 `screens/*.body.html`。
AXIOM 只改视觉层，不改任何功能编排，因此两者可以随时来回切换。

### 落地建议（AXIOM 版）

1. 替换 `globals.css` 的 `:root` / `.dark` 变量为 AXIOM 取值 → 观感立刻换成商务范
2. 顶栏 `TopBar` 加 `.topnav` 深底样式与金色底线，logo 换金色印记
3. 现有写死颜色的小组件（封面渐变、AI orb、头像）按上文调色板映射表替换
4. 卡片阴影清零，改用 1px 描边分层；圆角全局收到 2–5px
5. 全站数字加 `font-variant-numeric: tabular-nums`
